# ALGO3 · Algorithmics and Data Structures (USTHB)

Course materials: chapters, TD series and solutions.

All documents are stored encrypted. An item is visible to students only when its key
is written in `unlock.txt`.

## Unlock or lock an item
1. Open `unlock.txt` in this repository and click the pencil icon (Edit).
2. After the `=` of the item line (for example `course-1 =`), paste its key from the private KEYS file.
3. Click **Commit changes**. The site is updated within 1 or 2 minutes.

To lock an item again, delete its key.
